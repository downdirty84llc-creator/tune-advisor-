# Finance, KPI, and Management Workflows

---

## Daily owner brief

| Block                 | Contents                                                                           |
| --------------------- | ---------------------------------------------------------------------------------- |
| **Decisions needed**  | Only approvals, with amount, deadline, recommendation, risk, and exact next action |
| **Revenue**           | Collected today, deposits, pending invoices, failed payments, refunds/disputes     |
| **Pipeline**          | New leads, quotes sent, quotes accepted, stalled high-value opportunities          |
| **Operations**        | Today's appointments, readiness blocks, overdue jobs, file delivery queue          |
| **Customers**         | Negative sentiment, safety concerns, missed promises, VIP or partner issues        |
| **Cash and spend**    | Available operating cash, planned purchases, budget exceptions                     |
| **Top three actions** | The highest-value owner actions that cannot be delegated                           |

Format in `05-Reports/Daily/README.md`.

## Weekly scorecard

| Metric                       | Definition                                                               | Initial target                                      |
| ---------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------- |
| **Lead response time**       | Median time from inquiry to first meaningful response                    | Under 5 min automated; under 2 business hours human |
| **Qualification completion** | Qualified leads with all required data before quote                      | 90%+                                                |
| **Quote turnaround**         | Median time from qualified lead to sent quote                            | Under 15 min standard; same day custom              |
| **Quote conversion**         | Accepted quotes / valid quotes sent                                      | Track by service, source, and price tier            |
| **Collected revenue**        | Cleared customer payments in period                                      | Weekly target set from the monthly plan             |
| **Gross margin**             | Revenue less direct labor, travel, credits, parts, fees, outsourced work | Never below the approved floor without exception    |
| **Average order value**      | Collected revenue / paid jobs                                            | Increase through relevant add-ons, not pressure     |
| **Cycle time**               | Accepted/deposit to closed job                                           | Track by service type                               |
| **On-time completion**       | Jobs completed within the committed window                               | 90%+ initially                                      |
| **Rework / complaint rate**  | Jobs requiring correction or formal complaint / closed jobs              | Declining trend; root cause every case              |
| **Cash collection speed**    | Days from invoice to payment                                             | Same day for consumer work where policy permits     |
| **Owner hours**              | Time owner spends on admin, sales, and coordination                      | Reduce monthly while outcomes improve               |

## Margin calculation

```
  Collected revenue
- payment processing fees
- software credits / licenses consumed
- direct parts and shipping
- direct subcontractor cost
- travel cost (miles x internal cost rate + tolls)
- direct labor cost allocation
= contribution margin

contribution margin / collected revenue = contribution margin percentage
```

Full rules, including the unknown-input rule and the margin floor, in `03-Knowledge/margin-formula.md`.

## Weekly management review

1. **Review exceptions first:** safety, disputes, overdue cash, overdue jobs, broken automations, negative customer sentiment.
2. Review the scorecard against target and the prior four-week average.
3. Identify the single largest **revenue leak** and the single largest **time leak**.
4. Approve, reject, or revise proposed SOP, pricing, campaign, and automation changes.
5. Set next-week capacity, offers, purchasing limits, and the owner's top three outcomes.
6. Archive decisions in the knowledge base so agents use the latest policy.

Step 6 is the one that gets skipped. A decision that lives only in the owner's head is a decision the system will contradict next week.
