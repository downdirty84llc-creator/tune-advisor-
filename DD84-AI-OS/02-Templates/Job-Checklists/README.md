# Job Checklists

**Used by:** S06 Service Delivery, S07 Quality/Safety/Risk, S04 Scheduling

---

## Job readiness gate

Run before any job starts. Every row must pass, or the job is `Blocked` with a stated correction.

- [ ] **Scope** — accepted quote matches the job record; no undocumented change
- [ ] **Payment** — required deposit/payment status met; not failed or disputed
- [ ] **Vehicle/build data** — engine, transmission, software, and modification state known
- [ ] **Files** — required customer files received, validated, named, and linked
- [ ] **Tools/access** — hardware, credits, software, cables, adapters available; module not locked
- [ ] **Location/time** — address, arrival window, travel buffer, customer availability confirmed
- [ ] **Risk** — no unresolved safety, legal, or compliance block
- [ ] **Expectation** — customer has acknowledged the outcome-dependency language

---

## Release checklist — S07 gate

Nothing reaches a customer until every box is checked.

- [ ] Correct customer, vehicle, job, and file version
- [ ] All required evidence attached and reviewed
- [ ] No unresolved safety, legality, compatibility, or payment block
- [ ] **Owner release status explicitly recorded in the job record**
- [ ] Delivery instructions match the exact service and hardware
- [ ] Rollback / recovery instructions exist where applicable
- [ ] Next log or verification step scheduled
- [ ] Customer-facing claims do not exceed measured or supportable results

---

## Mobile pre-trip checklist

- [ ] Address confirmed, with parking and workspace suitable
- [ ] Weather contingency decided
- [ ] Vehicle access arranged; adult contact on site
- [ ] Battery condition and required fuel confirmed
- [ ] Route generated; travel fee and arrival window set
- [ ] Tools, cables, chargers, parts, and files packed against the packet
- [ ] Arrival reminder and preparation instructions sent
- [ ] **24-hour confirmation received** — no confirmation means escalate, not roll

## Mobile on-arrival checklist — owner performs

- [ ] Verify vehicle identity against the job record
- [ ] Verify scope with the customer before starting
- [ ] Document pre-existing condition and any damage, with photos
- [ ] Confirm any scope change in writing before performing it

---

## Closeout checklist

- [ ] Notes, photos, scan results, and timestamps recorded
- [ ] Any customer-approved scope change documented
- [ ] Owner has confirmed technical completion
- [ ] Owner release recorded for any file delivered
- [ ] Invoice / receipt sent
- [ ] Aftercare instructions sent
- [ ] Outstanding risks documented
- [ ] Next log or verification scheduled
- [ ] Review request queued — **held if any issue is unresolved**
- [ ] Lessons-learned entry created if anything surprised us
