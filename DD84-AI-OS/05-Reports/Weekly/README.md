# Weekly Scorecard and Management Review

Generated at weekly close by S10 (metrics) and S12 (improvement proposals).

---

## Scorecard

| Metric | Definition | Initial target | This week | 4-wk avg | Variance |
|---|---|---|---|---|---|
| **Lead response time** | Median inquiry → first meaningful response | Under 5 min automated; under 2 business hrs human | | | |
| **Qualification completion** | Qualified leads with all required data before quote | 90%+ | | | |
| **Quote turnaround** | Median qualified lead → sent quote | Under 15 min standard; same day custom | | | |
| **Quote conversion** | Accepted quotes / valid quotes sent | Track by service, source, price tier | | | |
| **Collected revenue** | Cleared customer payments in period | Weekly target from monthly plan | | | |
| **Gross margin** | Revenue less direct labor, travel, credits, parts, fees, outsourced | Never below approved floor without exception | | | |
| **Average order value** | Collected revenue / paid jobs | Increase through relevant add-ons, not pressure | | | |
| **Cycle time** | Accepted/deposit → closed job | Track by service type | | | |
| **On-time completion** | Jobs completed within committed window | 90%+ initially | | | |
| **Rework / complaint rate** | Jobs requiring correction or formal complaint / closed jobs | Declining trend; root cause every case | | | |
| **Cash collection speed** | Days from invoice to payment | Same day for consumer work where policy permits | | | |
| **Owner hours** | Time owner spends on admin, sales, coordination | Reduce monthly while outcomes improve | | | |

**Owner hours is the headline metric.** The whole system exists to move it down while everything else holds or improves. If owner hours are flat, the deployment is not working, regardless of how good the other numbers look.

---

## Weekly review agenda

1. **Exceptions first.** Safety, disputes, overdue cash, overdue jobs, broken automations, negative sentiment.
2. Scorecard against target and the prior four-week average.
3. The single largest **revenue leak** and the single largest **time leak**.
4. Approve, reject, or revise proposed SOP, pricing, campaign, and automation changes.
5. Set next-week capacity, offers, purchasing limits, and the owner's top three outcomes.
6. Archive decisions in the knowledge base so agents use the latest policy.

---

## Also reviewed weekly

- Revenue, contribution margin, cash, receivables, planned spend
- Pipeline by source, service, probability, value, next action
- Capacity and schedule constraints
- Customer issues and root causes
- Marketing attribution and the next experiment
- Automation failures, false positives, false negatives, permission changes

---

## Output of the review

Every review produces at least one **committed corrective action** with an owner, a due date, and a way to tell whether it worked. A review that produces only observations was a status meeting, not a review.
